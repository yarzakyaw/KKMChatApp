Steps to Configure IPFS for LAN Access
Open the IPFS Configuration File:
You will need to edit your IPFS configuration file, which is located at C:\Users\User\.ipfs\config. You can open this file using Notepad or any text editor. Here’s how to do it:

powershell
notepad C:\Users\User\.ipfs\config  
Locate the Addresses Section:
In the configuration file, look for the Addresses section. It should look something like this:

json
"Addresses": {  
   "API": "/ip4/127.0.0.1/tcp/5001",  
   "Gateway": "/ip4/127.0.0.1/tcp/8080",  
   "Swarm": [  
       "/ip4/127.0.0.1/tcp/4001",  
       "/ip6/::1/tcp/4001"  
   ]  
}  
Modify Addresses:
Change the API, Gateway, and Swarm addresses to allow connections from your local network. Replace 127.0.0.1 with 0.0.0.0 to listen on all network interfaces. The modified section should look like this:

json
"Addresses": {  
   "API": "/ip4/0.0.0.0/tcp/5001",  
   "Gateway": "/ip4/0.0.0.0/tcp/8080",  
   "Swarm": [  
       "/ip4/0.0.0.0/tcp/4001",  
       "/ip6/::/tcp/4001"  
   ]  
}  
This change allows your IPFS node to accept connections from any IP address assigned to your network interfaces.

Save the Changes:
After making the changes, save the file and close Notepad.

Restart the IPFS Daemon:
You will need to stop and then restart the IPFS daemon for the changes to take effect. If it's running, use Ctrl + C to stop it, then start it again with:

bash
ipfs daemon  
Accessing the IPFS Node from Other Devices on the LAN
Now that you've configured your IPFS node to accept connections from any address:

Find Your Local IP Address:
You can find your local machine's IP address by running the following command in PowerShell:

powershell
ipconfig  
Look for the IPv4 Address under your active network connection (usually something like 192.168.x.x).

Connecting from Other Devices:
You can now access the IPFS API or Web UI from other devices on the same network using your local IP address. For example:

Access the Web UI: http://<YourLocalIPAddress>:5001/webui
Access the API: http://<YourLocalIPAddress>:5001/api/v0/

You're on the right track with your approach to sending files in a decentralized application (dApp) using IPFS. Since you want to add file-sharing functionality to your existing Solidity contract, here’s how you can implement it:

Steps to Implement File Sending
Store Files on IPFS:

First, you need to upload the file (like documents or images) to IPFS. This can be done using libraries like ipfs-http-client in your React frontend. After uploading, you will receive a unique IPFS hash that represents the file.
Modify the Solidity Contract:

You will need to add a new function in your contract to handle file links. This function will accept the IPFS hash and store it in a way similar to how messages are stored.
Send the IPFS Link:

When sending a file, you will send the IPFS link instead of a text message.

Upload File to IPFS:
Here’s an example of how to upload a file and then send it using your contract:

javascript
import { create } from 'ipfs-http-client';  

const ipfs = create({ url: 'https://ipfs.infura.io:5001/api/v0' });  

const uploadFile = async (file) => {  
    const added = await ipfs.add(file);  
    return added.path; // This is the IPFS hash  
};  

const sendFile = async (file, friendAddress) => {  
    const ipfsHash = await uploadFile(file);  
    await contract.methods.sendFile(friendAddress, ipfsHash).send({ from: userAccount });  
};
